# INC-7302 — Reconnect storm during deploys

Severity: S2 · Reported by: Plataforma · Status: open, not diagnosed

## What we observed
- During each rolling deploy, `GET /api/realtime/stream` jumps from a few requests per minute to ~1 request per
  second per open browser tab, for the whole drain window of the old replica (up to 30 s), and sometimes longer.
- Access log on the draining replica: each of these requests returns `200`, the response body is ~60 bytes (the
  `connected` event and a `: ping`) and the connection closes a few milliseconds later.
- In a browser, DevTools shows the stream reconnecting every second during that window, each time receiving the
  `connected` event, instead of backing off.
- When the API is fully down (connection refused), browsers back off as expected (1 s, 2 s, 4 s, … up to 30 s).
