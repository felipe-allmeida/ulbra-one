# INC-9102 — "Erro inesperado" when pasting a PIX copia e cola into the PIX field

**Reported by:** Contas a Pagar, Solicitações
**Severity:** high — the título cannot be saved at all

## What users see

- An analyst received an Itaú cobrança and pasted its copia e cola (a long text starting with `000201…`) into the PIX field of the título form, which is the only PIX field the form has. On save: *"Erro inesperado. Tente novamente."*
- Same result when editing an existing título and pasting the copia e cola there.
- A requester pasting a copia e cola into the PIX field of a solicitação's payment plan gets the same generic error.
- Typing a normal PIX key (e-mail, CNPJ) in that field works.

## From the API logs (excerpt)

```
POST /api/payables → 500
Microsoft.EntityFrameworkCore.DbUpdateException: An error occurred while saving the entity changes.
 ---> Npgsql.PostgresException: 22001: value too long for type character varying(100)
```

## Notes from the analysts

- Some analysts started cutting the text to make it fit. Those títulos saved, but treasury says the remittance for them is now wrong. Please make sure the system never accepts a cut copia e cola as a key.
